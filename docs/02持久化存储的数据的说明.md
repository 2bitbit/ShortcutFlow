## 0. 数据存储位置
主要的数据存放在：可执行文件所在的文件夹。
备注：
  - 这并不意味着 SF 是纯绿色软件。将 SF 放入U盘在不同电脑上运行，主体功能可以正常运行。但其他功能不一定可以正常运行。

## 1. 目录说明

### 1.1 **`ShortcutFlows/`** 
- 内容：单个流对应单个`.json`文件。

- 给开发者的备注：
  1. 调试流（文件名以 `__debug_` 开头）与普通流一同存放在 `setup/ShortcutFlows/` 中。在开发阶段（通过 `debug_overwrite_debug_dirs.py` 同步）可用；在发布打包时由 `release_01_bundle.py` 通过 `-x!__debug*` 排除，不会出现在最终压缩包中。
  2. 用户通过 UI 新建的流：前端自动生成 UUID 作为文件名（`{uuid}.json`）防冲突。内置流：使用 `__builtin_` 前缀的约定式 ID（如 `__builtin_SmartDict_flow`）。（不用名字的原因：会有在不同流分组下创建相同名称工作流的需求（例如都名叫"测试"））

### 1.2 **`BuiltinComponents/`**
- 内容：单个内置组件对应单个**同名**目录。

### 1.3 **`CustomComponents/`** 
- 内容：单个自定义组件对应单个**同名**目录。
（文件系统层面已经保证了自定义组件不会重名）

- 备注：
  1. **节点执行时的默认工作目录为其对应的组件的目录**，除非被流的工作路径强制覆盖。（您可以把相关资源全部整理到组件所在的目录。）
  2. 组件的名字作为唯一标识。
  3. 自定义组件的本质：本质是内置组件 `shell` 的特定封装。

## 2. 文件说明
- ui_settings.json：持久化存储了 UI 的每一个组的折叠状态。
